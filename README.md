## 📖 Overview

CropMind is an AI-powered smart agriculture platform developed for the **Build with Gemma: AI for Africa Hackathon 2026**.

The platform helps farmers identify crop diseases from leaf images, receive expert treatment recommendations, interact with an AI farming assistant, and access agricultural knowledge through a modern, intuitive interface.

CropMind aims to reduce crop losses, improve food security, and make agricultural expertise more accessible to smallholder farmers across Africa.

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/bnbaztech/CropMind.git
```

Navigate into the project

```bash
cd CropMind
```

Install dependencies

```bash
npm install
```

Create an environment file

```env
GEMINI_API_KEY=YOUR_API_KEY
```

Run the development server

```bash
npm run dev
```

---

# 🏗 Build

```bash
npm run build
```

Start production server

```bash
npm start
```
